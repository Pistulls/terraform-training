# HashiCorp Certified: Terraform Associate (004) training material

This site is deployed [here](https://terraform-training.peterlester.dev/)

## Run locally

```bash
python3 -m http.server 8090 --directory site
```

## What is this?

Training material for `HashiCorp Certified: Terraform Associate (004)` generated by Claude, based on the API docs at the time.

As this was generated by AI it can contain mistakes however, I used this for my own training, I have been through it multiple times before taking the exam.

Progress is stored using `localStorage` in your browser, there is no backend to this, simple, static HTML/JS/CSS

## Why does this exist?

Courses such as Udemy can be very slow to get to the point. The actual HashiCorp training is pretty hard to work through, it's mostly API docs and very wordy explanations. This aims to distill down the key points for the entire course material and allow for quick quiz of knowledge to verify understanding.

I've deployed this simply incase anyone wanted to use it. If you find mistakes you can submit a change or open an issue.
